# MCP 模型上下文协议：系列目录与导读

> 📦 配套代码仓库（含全部图表源码与一个**可运行**的 MCP 服务器）：<https://github.com/geekchow/mcp-explain>

这是一个把 **MCP（Model Context Protocol，模型上下文协议）** 从"为什么必须发明它"一路讲到"每个组件内部怎么工作"的系列。它不是规范的翻译，而是一条**认知路径**：

```
为什么 → 是什么 → 概念地图 → 贯穿示例 → 逐组件深入 → 完整走查
（痛点）  （定义）   （全部概念   （一个场景，   （每个关键组件   （把示例端到端
                    与组件）     先浅层走一遍）  一篇，锚回示例）  全深度重跑）
```

全系列由**同一个真实场景**串起来：工程师 Ana 在 Claude Code 里排查一批卡在 `PENDING_PAYMENT` 状态超过 24 小时的订单，逐笔到支付网关核对，并对其中从未扣款成功的发起退款。这一个请求会穿过两个刻意设计成完全相反的 MCP 服务器——一个走 **stdio**、只读、在仓库内；一个走 **Streamable HTTP**、带 **OAuth 2.1**、会动真金白银——从而把全部概念和全部组件都触及一遍。

## 阅读建议

- **第一次读**：按 1→11 顺序读，不要跳。每一篇都建立在前一篇的词汇之上，且从不重复定义。
- **之后回查**：六到十这五篇是自包含的，每篇开头回顾组件职责、结尾锚回贯穿示例，可以单独跳读。
- **想动手**：直接去仓库里的示例服务器，它**不需要数据库**就能跑：

```bash
git clone https://github.com/geekchow/mcp-explain.git
cd mcp-explain/mcp-guide/examples/orders-db-server
npm install && node index.js
```

然后在同目录用 `claude` 连上它，或者干脆用 `printf` 手搓 JSON-RPC 报文——本系列引用的每一段协议报文，都是从这个服务器上真实抓下来的，不是编的。

## 关于版本

本系列描述的是 **`2025-06-18`** 修订版，也是当前 Claude Code 与官方 SDK 默认协商的版本。凡是某个特性在特定版本才引入的（Streamable HTTP 在 `2025-03-26`，征询与结构化工具输出在 `2025-06-18`），正文都会点明。更新的修订版还会增加特性，但本系列中的每一个概念在各版本间都是稳定的。
